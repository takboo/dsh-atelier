# 开发与验证

## 模块职责

| 路径 | 职责 |
| --- | --- |
| `src/identity.js` | 公开插件 ID，与包名、模块工厂及 Cordis 行一致。 |
| `src/client.js` | DSH 注册入口：字典、主题、样式和插槽的生命周期。 |
| `src/runtime.js` | 主题控制器：选择、原生接管、恢复、订阅与清理。 |
| `src/preferences.js` | 偏好验证、旧格式迁移和可失败的浏览器存储。 |
| `src/themes.js` | 六套风格定义与语义 token 生成。 |
| `src/gallery.js` | 画廊与卡片预览，通过外部快照订阅状态。 |
| `src/locale.js` | 画廊界面的中英文字典。`locale/` 保存插件管理页元信息。 |
| `src/styles/` | 全局风格材质与画廊局部排版。 |
| `client.js` | 随包分发的生成产物，由构建脚本打包为 DSH 模块工厂。 |
| `tests/` | 偏好和实际客户端入口的回归测试。 |
| `scripts/preview/` | 使用实际画廊和官方主题运行时的隔离浏览器宿主。 |

发布和商店收录见 [RELEASING.md](RELEASING.md)。

## 本地工作流

```sh
npm ci
npm run check
npm run dev
```

`npm run dev` 默认监听 `http://127.0.0.1:4173`；用 `PORT` 修改端口，`/?lang=en` 预览英文。源码修改后重启预览服务。它使用独立浏览器源的存储，不连接真实 DSH、账号或会话。

`npm run check` 构建后执行 Node 测试、浏览器检查与发布包核验。浏览器检查使用临时配置并在退出时关闭浏览器。默认探测常见 Chrome/Chromium 路径，也可指定：

```sh
CHROME_PATH="/path/to/chrome" npm run test:ui
```

浏览器启动被运行环境沙箱阻止时，需要在允许启动浏览器的环境执行该检查；将这种情况报告为未完成，不能用 Node 测试代替。

## 主题服务约定

运行时只通过官方 `ctx.theme` 接口写主题。六套定义注册为 `atelier-*`；实际选择使用原生 `light`／`dark`／`system` 模式，并叠加同一来源的明暗 token 对。这样，rc.5 保存字体设置后重新采用持久化原生偏好，也能保持 Atelier 配色。切换到第三方临时主题 ID 不能保证这种行为。

控制器将自身写操作与外部主题变更分开。自写操作期间的重入事件不会被当作原生接管；外部改选模式或主题 ID 时，控制器撤销覆盖并发布空选择。Gallery 使用 `useSyncExternalStore` 读取稳定快照，使已打开的画廊也能立即反映接管与系统明暗变化。

进入 Atelier 前记录最新原生偏好，恢复时使用这份值。仅在有已保存搭配的启动路径读取历史恢复值；未启用风格时跟踪原生服务的变化。停用时先取消订阅，再移除覆盖层和恢复原生，避免清理期间重新应用插件状态。

全局 CSS 通过 `data-atelier-style` 限定作用范围。主区域使用渲染器的 `data-slot="main"` 标记；新建会话按钮按完整类名后缀匹配，不绑定构建哈希，也不命中 `newSessionContent` 等后代类名。这些后缀仍是宿主实现细节，支持范围固定为 manifest 声明的版本。新增宿主版本前检查真实 DOM、选择器命中及视觉效果。

## 测试范围

- **Node 集成测试**：加载构建后的真实 `client.js` 与 npm 中固定版本的官方 `ThemeRuntime`，替换 Cordis、DOM 和存储适配器。覆盖原生三种模式接管、连续恢复与再激活、系统搭配、字体持久化后采用、旧格式迁移、存储失败、订阅刷新、其他主题接管和停用清理。
- **浏览器检查**：运行实际画廊，验证 rc.5 类名夹具上的按钮材质、后代不误命中、主题搭配、原生接管、恢复、刷新持久化、字体调整、390px 布局、键盘操作和英文文案。宿主框架是预览适配器，不能代替真实安装验证。
- **打包检查**：`npm pack --dry-run` 检查运行入口、patch、图标、元信息、产品文档与截图的覆盖。包内不需要开发依赖。

更改后执行：

```sh
npm run check
npm pack --dry-run
```

源码与生成产物一起提交。`npm pack` 的 `prepack` 会重新构建，支持从 tgz 安装。`engines.dsh` 固定为 `0.2.1-rc.5`；扩大兼容范围需要新增宿主验证。

## 维护演示截图

```sh
npm run screenshots
```

命令执行浏览器回归，并从当前 Gallery 截取 `docs/assets/gallery-light.png` 和 `gallery-dark.png`。固定使用 1440px 视口、中文、减少动态效果，以及青瓷／午夜霓虹搭配。截图只包含真实画廊区域；画面外的原生模式按钮和 DOM 夹具属于验证工具。

本轮截图与浏览器检查环境为 macOS、Chrome、官方主题包 rc.5。静态截图足以展示六套风格与两种明暗；交互可通过本地预览体验，暂不维护额外 GIF。

## 真实宿主验收

在独立测试 profile 安装同一份 tgz，再检查：侧栏入口、会话输入区／消息／代码块、菜单／弹窗、系统明暗、原生设置接管、字体设置、停用及重新启用。Desktop 还要检查 macOS 收起侧栏时的原生窗口控件避让、Windows 标题栏和 Linux 窗口布局。记录宿主版本、系统与包摘要。

本仓库的自动检查不等同于这些平台的安装、原生窗口与视觉验收。本轮未改动实际 DSH profile，也未完成这些验收。
