# 使用 Atelier

安装入口、版本要求和截图见[产品首页](../README.md)。

## 切换与保存

画廊分别保存一套浅色、一套深色风格。顶部的浅色／深色／跟随系统控制实际外观模式；“全部风格／浅色／深色”只筛选卡片。

跟随系统时，当前明暗由 DSH 原生主题服务解析，切换另一种明暗的搭配不会强制改变当前外观。手动模式下，点击另一种明暗的风格会同时切换模式。

选择只保存在当前浏览器、当前源（协议、主机和端口）的 `localStorage`，不写入账号，也不在设备之间同步。浏览器禁止存储时仍可实时使用，但刷新后需要重新选择。旧版 `liquid` 风格及搭配会转换为青瓷造物。

## 恢复、接管与停用

- **恢复原生**：移除主题覆盖和风格材质，恢复最近一次进入 Atelier 前的 DSH 浅色／深色／跟随系统偏好。
- **从 DSH 设置切换**：在原生设置中改选另一种外观模式，会退出 Atelier，清除已保存的风格选择，并保留新选的原生模式。点击已经选中的原生模式不会产生主题变化；要移除当前风格，请用画廊中的“恢复原生”。
- **停用插件**：注销主题、监听器、样式和覆盖层，恢复原生模式；保留 Atelier 搭配，便于再次启用。停用前先点击“恢复原生”，可同时清除搭配。
- **其他主题插件**：从其他插件切换到不同的主题 ID 时，Atelier 会让出主题控制。多个插件同时叠加 token 覆盖的结果取决于注册顺序，建议只启用一个全局换肤插件。

## 字体与动态效果

正文、代码、终端的字体和字号继续在 **DSH 设置**中管理。Atelier 的风格 token 不含字体设置；画廊使用独立的界面排版，正文大小设置主要作用于 DSH 会话内容。

系统的减少动态效果偏好会关闭画廊卡片位移和插件添加的界面过渡。青瓷使用不透明表面，不依赖背景模糊；午夜霓虹保留发光及部分透明材质。

## 排查问题

| 现象 | 检查方法 |
| --- | --- |
| 没有风格画廊入口 | 确认使用 rc.5、组合包及其插件行已启用，刷新界面；按宿主提示重启。 |
| 卡片选中了但界面未变化 | 跟随系统时，另一种明暗的风格只保存到搭配。检查顶部“当前风格”。 |
| 刷新后回到原生 | 确认浏览器允许本地存储，并且 DSH 地址和端口没有改变。 |
| 新建会话、输入框等局部细节没有变化 | 检查宿主版本及其他换肤插件。宿主 DOM 变化需要兼容性复查。 |
| 想彻底恢复原生 | 在画廊点击“恢复原生”，然后在插件管理页停用或卸载。 |

报告问题时附上 DSH 版本、系统、浏览器、所选风格、明暗模式与复现步骤。截图使用空白会话或示例内容，移除个人会话与凭据。
