# Atelier · 风格画廊

一个纯客户端的 DeepSeek Harness 视觉主题插件。安装后，左侧边栏会出现“风格画廊”入口。

## 六种风格

- **方块远征（Dark）**：草木、岩石、泥土与火把微光，以方块厚度和材质代替街机霓虹。
- **纸上花园（Light）**：暖纸色、鼠尾草绿、柔和圆角与轻盈阴影。
- **午夜霓虹（Dark）**：深紫底色、青蓝与紫粉高光、发光边缘。
- **包豪斯工坊（Light）**：三原色、非对称几何与留白，使用细线和现代印刷式构成。
- **黑白极简（Dark）**：高对比黑白、克制边框与紧凑圆角。
- **青瓷造物（Light）**：白瓷、青玉、松烟墨与朱砂印，以开片纹理、釉色渐变和器物阴影构成安静的东方现代界面。

每套主题除语义色板外，还包含独立的导航、输入区、消息气泡、代码块、标签页、边框和材质规则。画廊使用真实 DOM 组件结构生成预览。

可分别选择一套 Light 和 Dark 主题，并使用浅色、深色或跟随系统三种模式。跟随系统由 DSH 原生 `system` 外观服务监听并解析，Atelier 仅向当前明暗应用对应搭配的样式；手动模式下选择另一组主题会切换到对应明暗。旧版单主题设置及液态玻璃的 Light 搭配会自动迁移。

选择保存在当前浏览器的 `localStorage` 中。“恢复原生”会移除自定义风格，并恢复此前的 DSH 浅色／深色偏好。

青瓷造物使用不透明的白瓷表面和低对比度开片纹理，不依赖透明或背景模糊。朱砂主按钮、青玉导航、釉金代码侧线与瓷盘式预览贯穿整套主题；系统减少动态效果偏好仍适用于界面过渡。

插件通过 DSH 主题服务注册主题，不设置或覆盖 `font-family`、正文字号、代码字号及终端字号。
